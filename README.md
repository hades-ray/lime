## О проекте

**Lime** — это полнофункциональный веб-сайт маркетплейса, созданный в рамках курсовой работы. Проект демонстрирует типичную архитектуру онлайн-платформы для торговли: пользователи могут регистрироваться, создавать собственные магазины, управлять товарами и взаимодействовать с платформой через административную панель.

Проект реализован на «чистом» PHP без использования фреймворков, что делает его идеальным учебным примером для понимания основ веб-разработки: работа с сессиями, SQL-запросами, загрузкой файлов и базовой безопасностью.

### Цели проекта
- Демонстрация полного цикла создания веб-приложения
- Изучение паттернов работы с базами данных
- Создание основы для дальнейшего расширения и коммерциализации

## Основные возможности

### Для пользователей
- **Регистрация и авторизация** — простая система аутентификации с хешированием паролей
- **Личный профиль** — просмотр и редактирование информации, смена аватара
- **Создание магазина** — любой пользователь может стать продавцом
- **Управление товарами** — добавление, редактирование товаров в своем магазине
- **Просмотр магазинов** — каталог магазинов других пользователей

### Для администраторов
- **Административная панель** — отдельный интерфейс для управления контентом
- **Модерация** — возможность управлять пользователями, магазинами и товарами

### Технические особенности
- **Готовая верстка** — адаптивные CSS-стили для корректного отображения на разных устройствах
- **Загрузка файлов** — поддержка аватаров пользователей и изображений товаров
- **Безопасность** — базовая защита от SQL-инъекций через экранирование данных

## Быстрый старт

### Системные требования
- **Веб-сервер:** Apache 2.4+
- **PHP:** 7.4 или выше (рекомендуется 8.0+)
- **MySQL:** 5.7 или выше (рекомендуется 8.0+)
- **Браузер:** современная версия Chrome, Firefox, Safari или Edge
